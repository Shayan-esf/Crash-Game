# 🚀 بازی انفجار کیهانی (Cosmic Crash Game) — Telegram Mini App

یک بازی جذاب و مدرن **Crash (انفجار)** در قالب **Telegram Mini App**، ساخته‌شده با معماری زمان‌واقعی (Real-Time)، رندرینگ ۶۰fps مستقیم روی HTML5 Canvas، تراکنش‌های مالی اتمیک، بازخورد لرزشی بومی تلگرام (**Haptics**)، اشتراک وایرال تلگرامی (**Viral Share**)، سیستم استریک روزانه ۷ روزه (**Daily Streak**) و راستی‌آزمایی منصفانه بودن (**Provably Fair**).

## 🛠 معرفی پروژه و پشته فناوری

این پروژه به سفارش پیاده‌سازی یک بازی تلگرامی شبیه‌ساز انفجار با اعتبار مجازی (۱۰۰۰ سکه اولیه) طراحی شده است. بازی فاقد هرگونه درگاه پرداخت واقعی بوده و صرفاً با اهداف سرگرمی و سنجش ریسک توسعه یافته است.

### Tech Stack
- **Frontend Core**: [Next.js 15 (App Router)](https://nextjs.org/) با [React 19](https://react.dev/) و [TypeScript](https://www.typescriptlang.org/)
- **UI & Design System**: Tailwind CSS v3، رادیکس یو‌آی (Radix UI)، آیکون‌های Lucide و طراحی فضایی تاریک اختصاصی (**Cosmic Arcade**) مطابق سند `DESIGN.md`
- **State Management**: [Zustand](https://github.com/pmndrs/zustand) برای هماهنگی کلاینت و کیف پول
- **Graphics Engine**: بوم اختصاصی HTML5 Canvas 2D با مقیاس‌بندی برداری رتینا (`window.devicePixelRatio`)، فیزیک ذرات پلاسما و ستاره‌های متحرک پرالاکس ۶۰ فریم بر ثانیه
- **Database & ORM**: SQLite محلی (Zero-Dependency) هماهنگ‌شده از طریق [Prisma ORM](https://www.prisma.io/)
- **Real-Time Engine**: سرور مجزای وب‌سوکت Node.js (`ws-server.js`) با صف حافظه Pub/Sub داخلی بدون نیاز به سرویس ردیس
- **Telegram Platform**: کتابخانه رسمی `@telegram-apps/sdk`، اسکریپت `telegram-web-app.js` و ربات لانچر سبک Node.js (`server/bot.js`)

## ✨ قابلیت‌ها و امکانات کلیدی

1. **اشتراک‌گذاری وایرال در تلگرام (Telegram Viral Share)**:
   - دکمه اختصاصی «اشتراک در تلگرام 🚀» پس از Cash Out موفقیت‌آمیز و در سوابق بازی.
   - تولید مستقیم لینک `https://t.me/share/url` حاوی رکورد ضریب، سود خالص و لینک دعوت بازی جهت ارسال در چت‌ها و گروه‌ها.
2. **گردونه شانس روزانه و استریک ورود ۷ روزه (Daily Streak & Spin Wheel)**:
   - گردونه شانس تعاملی ۸ خانه (`[50, 100, 150, 200, 250, 350, 500, 1000]` سکه) با انیمیشن فیزیک چرخش و کاهش شتاب واقع‌گرایانه و هپتیک.
   - ضرب پاداش برنده در ضریب زنجیره ورود روزانه (روز ۱ تا ۷: ضرایب `[1.0x, 1.2x, 1.4x, 1.6x, 1.8x, 2.0x, 2.5x]`) جهت کاهش نرخ ریزش کاربر (Churn Rate).
   - امکان چرخش مجدد با پرداخت ستاره تلگرام (**Telegram Stars ⭐**) از طریق فاکتور بومی `Telegram.WebApp.openInvoice`.
   - مهلت ۲۴ ساعته چرخش رایگان بعدی و مهلت ۴۸ ساعته حفظ زنجیره استریک.
3. **بازخورد لرزشی بومی تلگرام (Native Haptics)**:
   - بازخوردهای ارتعاشی لمسی بومی تلگرام (`impactOccurred('light' | 'medium')` و `notificationOccurred('success' | 'error')`) در انتخاب چیپ، ثبت شرط، برداشت سود و انفجار موشک.
4. **برداشت خودکار و ناوگان فضاپیما (Auto Cash Out & Ship Tiers)**:
   - پریست‌های برداشت خودکار در ضرایب 1.5x, 2.0x, 3.0x, 5.0x, 10.0x و 20.0x.
   - ارتقای ۴ سطحی ظاهر سفینه در کنواس بر حسب ضریب انتخابی: راکت فالکون، جنگنده فانتوم، ناوشکن هایپردایو، و ناوبر کیهانی طلایی.
5. **راستی‌آزمایی عادلانه ریاضی (Provably Fair)**:
   - تعهد رمزنگاری قبل از آغاز راند با الگوریتم HMAC-SHA256 و محاسبه مجدد در مرورگر کاربر با Web Crypto API.
6. **شبیه‌سازی هم‌راندها (Multiplayer Simulation)**:
   - نمایش ۴ تا ۷ بازیکن فرضی در هر راند با وضعیت زنده شرط و کش‌اوت، با تگ شفاف `[شبیه‌سازی]`.
7. **تابلوی رکوردهای برتر (Leaderboard)**:
   - رده‌بندی برترین سودها و بالاترین ضرایب ثبت‌شده در میان کاربران.

## 🤖 ابزارهای هوش مصنوعی مورداستفاده (AI Tools)

در طول طراحی و پیاده‌سازی این بازی، از دستیارهای هوش مصنوعی پیشرفته به‌ویژه **Claude Code (Anthropic)** استفاده شده است:

1. **طراحی و پیاده‌سازی موتور بوم Canvas 2D**:
   - بازنویسی کامل انیمیشن آسمان دو‌بعدی به محیط خلأ کیهانی تاریک با ۹۰ ستاره دارای درخشش پرالاکس، رادارهای اسکن دایره‌ای هولوگرافیک و موج شوک انفجاری با لرزش دوربین (`Screen Shake`).
2. **مدل‌سازی تراکنش‌های مالی اتمیک**:
   - پیاده‌سازی ساختار کنترل همزمانی خوش‌بینانه در Prisma برای پیشگیری از حمله Double-Cashout ناشی از ارسال مکرر درخواست‌های همزمان شبکه.
3. **الگوریتم رمزنگاری Provably Fair**:
   - فرمول‌بندی تعهد اولیه بر پایه HMAC-SHA256 و فراهم کردن راستی‌آزمایی ریاضی با استفاده از Web Crypto API مستقیماً در مرورگر کاربر.
4. **شبیه‌سازی چندنفره هوشمند (Multiplayer Simulation)**:
   - نگاشت دترمینستیک بازیکنان هم‌راند بر پایه هش تصادفی راند، شبیه‌سازی کش‌اوت در ضرایب منطقی و درج صریح برچسب شبیه‌سازی برای شفافیت اخلاقی.

## ⚡ معماری و جریان داده زمان‌واقعی

سیستم از ۴ لایه مجزا تشکیل شده است:

```text
 ┌────────────────────────────────────────────────────────┐
 │           کاربران تلگرام (Telegram Mini App)           │
 └───────────────────────────┬────────────────────────────┘
                             │
            ┌────────────────┴────────────────┐
            ▼                                 ▼
   [HTTP REST APIs]                 [WebSocket Connection]
   - احراز هویت initData            - پخش زنده رویدادهای راند (Lobby)
   - پاداش روزانه (Daily Bonus)     - ثبت لحظه‌ای شرط‌ها
   - تاریخچه و رکوردهای برتر        - اعلام کش‌اوت با ضریب فعلی
            │                                 │
            ▼                                 ▼
   ┌─────────────────┐               ┌─────────────────┐
   │ Next.js Backend │               │  ws-server.js   │
   └────────┬────────┘               └────────┬────────┘
            │                                 │
            └───────────────┬─────────────────┘
                            ▼
               [Prisma ORM + SQLite Data Store]
               - Users (موجودی ۱۰۰۰ سکه)
               - GameSessions (هش، سید، ضریب)
               - Games (شرط، کش‌اوت، سود/زیان)
               - Transactions (لاگ تراکنش‌ها)
```

### چرخه حیات راند بازی (Game Loop States):
1. **فاز شرط‌بندی (`betting`) - مدت ۱۵ ثانیه**:
   - ایجاد شناسه راند جدید و تولید `seed` و `salt`.
   - محاسبه هش امنیتی `roundHash = HMAC-SHA256(seed:crashPoint, salt)` و ارسال به کلاینت‌ها.
   - شمارش معکوس روی رادار و پذیرش شرط‌های ۱۰، ۵۰ و ۱۰۰ سکه‌ای.
2. **فاز پرواز موشک (`flying`) - مدت متغیر تا ۲۰ ثانیه**:
   - اوج‌گیری پیوسته موشک و افزایش ضریب از 1.00x بر پایه تابع پیوسته زمانی.
   - فعال بودن دکمه برداشت سود دستی و مکانیزم برداشت خودکار (**Auto Cash Out**).
3. **فاز انفجار (`crashed`) - ۳ ثانیه**:
   - رسیدن به نقطه کرش، فعال شدن انیمیشن انفجار و شوک‌ویو.
   - افشای `seed` و `salt` برای راستی‌آزمایی توسط کاربر.
   - ثبت باخت برای شرط‌های برداشت‌نشده و شروع خودکار راند بعدی.

## 📐 فرمول و الگوریتم تعیین ضریب انفجار

روند رشد ضریب موشک در زمان پرواز از معادله نمایی زیر پیروی می‌کند:

$$M(t) = \exp\left( \frac{t}{T_{\text{max}}} \cdot \ln(k) \right)$$

که در آن:
- $t$: زمان سپری‌شده بر حسب میلی‌ثانیه از شروع پرواز
- $T_{\text{max}}$: حداکثر طول زمان پرواز راند (۲۰ ثانیه)
- $k$: ضریب مقیاس رشد بر حسب زمان

### تولید ضریب کرش در سرور (`ws-server.js`):
ضریب انفجار توسط مولد شبه‌تصادفی خطی (LCG) از روی Seed تصادفی راند تولید شده و بر اساس توزیع احتمالات وزن‌دار محاسبه می‌شود:

```javascript
// بازه‌های تصادفی وزن‌دار طبق استانداردهای بازی Crash
const DEFAULT_CRASH_CHANCES = [
  { min: 1.01, max: 1.5, weight: 45 }, // ۴۵٪ کرش‌های سریع زیر ۱.۵x
  { min: 1.5, max: 2.0, weight: 25 },  // ۲۵٪ ضرایب متوسط ۱.۵x تا ۲.۰x
  { min: 2.0, max: 5.0, weight: 20 },  // ۲۰٪ ضرایب مطلوب ۲.۰x تا ۵.۰x
  { min: 5.0, max: 10.0, weight: 7 },  // ۷٪ ضرایب بالا
  { min: 10.0, max: 50.0, weight: 3 }, // ۳٪ ضرایب استثنایی و انفجاری
];
```

حداقل ضریب همواره **1.01x** است و طبق نیازمندی‌های سند، کرش در 0.00x یا مقادیر منفی هرگز رخ نمی‌دهد.

## 🔒 مکانیزم منصفانه بودن تضمین‌شده (Provably Fair)

برای تضمین عدم دستکاری ضریب توسط سرور در حین پرواز موشک:

1. **مرحله تعهد (Commitment)**: قبل از آغاز راند، سرور ضریب نهایی را محاسبه کرده و هش زیر را تولید می‌کند:
   $$\text{Round Hash} = \text{HMAC-SHA256}(\text{seed} : \text{crashPoint}, \text{salt})$$
   این هش پیش از پرواز به تمام بازیکنان فرستاده می‌شود.
2. **مرحله افشا (Reveal)**: پس از انفجار موشک، سرور مقادیر `seed` و `salt` را علنی می‌کند.
3. **راستی‌آزمایی در کلاینت (Client Verification)**: در مدال **Provably Fair**، بازیکن با زدن دکمه «محاسبه و راستی‌آزمایی هش»، مستقیماً با کتابخانه امنیتی مرورگر (`window.crypto.subtle`) هش را مجدداً حساب کرده و انطباق قطعی آن را تایید می‌نماید.

## 💡 چالش‌های فنی کلیدی و راه‌حل‌ها

1. **جلوگیری از Double-Cashout ناشی از تاخیر شبکه**:
   - *چالش*: اگر کاربر در کسری از ثانیه چند بار دکمه کش‌اوت را فشرده یا چند درخواست همزمان بفرستد، خطر واریز چندباره سود وجود دارد.
   - *راه‌حل*: استفاده از `prisma.$transaction` با شرط به‌روزرسانی فقط در صورتی که رکورد شرط در وضعیت `'playing'` باشد (`updateMany({ where: { id, status: 'playing' } })`). در صورتی که تعداد رکوردهای تغییریافته صفر باشد، تراکنش فوراً ملغی می‌شود.

2. **حفظ پایداری ۶۰ فریم بر ثانیه در موبایل تلگرام**:
   - *چالش*: کتابخانه‌های سنگین بازی روی گوشی‌های ضعیف‌تر با افت فریم و لگ مواجه می‌شدند.
   - *راه‌حل*: رندر مستقیم بر پایه Native Canvas 2D API با استفاده از `requestAnimationFrame` و ضرب مقادیر در `window.devicePixelRatio` جهت دستیابی به نهایت وضوح و شارپنس بدون سربار فریم‌ورک‌های سنگین.

3. **حذف وابستگی به Redis و Docker**:
   - *چالش*: راه‌اندازی پروژه‌های معمولی نیازمند نصب کانتینرهای ردیس و دیتابیس خارجی است.
   - *راه‌حل*: استفاده از SQLite سبک با Prisma و طراحی یک سیستم توزیع پیام حافظه‌ای (In-Memory Pub/Sub) بر پایه EventEmitter استاندارد Node.js در `ws-server.js`. در نتیجه پروژه روی هر سیستمی تنها با دستور `npm run dev` بدون داکر اجرا می‌شود.

4. **تست و توسعه روان خارج از تلگرام (Dev Mode)**:
   - *چالش*: در مرورگرهای معمولی مقدار `window.Telegram.WebApp.initData` وجود ندارد.
   - *راه‌حل*: پیاده‌سازی Fallback خودکار در کلاینت و سرور وب‌سوکت که در غیاب تلگرام، یک کاربر تست با ۱۰۰۰ سکه می‌سازد تا آزمایش بازی و عملکردهای آن در هر مرورگری در دسترس باشد.

## 🚀 راهنمای راه‌اندازی و اجرای لوکال

### پیش‌نیازها:
- **Node.js** نسخه ۱۸ یا بالاتر
- **npm** یا **pnpm**

### ۱. کلون و نصب پکیج‌ها:
```bash
git clone <repository-url>
cd Crash-Game
npm install
```

### ۲. تنظیم متغیرهای محیطی (`.env`):
یک فایل به نام `.env` در ریشه پروژه بسازید (یا فایل پیش‌فرض را ویرایش کنید):
```env
# اتصال دیتابیس
DATABASE_URL="file:./dev.db"

# کلید ربات تلگرام (از BotFather@ در تلگرام)
BOT_TOKEN="YOUR_TELEGRAM_BOT_TOKEN"
TELEGRAM_BOT_TOKEN="YOUR_TELEGRAM_BOT_TOKEN"

# آدرس وب‌اپلیکیشن
WEBAPP_URL="http://localhost:3000"
NEXT_PUBLIC_APP_URL="http://localhost:3000"
NEXT_PUBLIC_WS_URL="ws://localhost:4001"
```

### ۳. آماده‌سازی دیتابیس SQLite:
```bash
npx prisma db push
```

### ۴. اجرای سرویس‌ها:

می‌توانید سرویس‌ها را در ترمینال‌های جداگانه اجرا فرمایید:

**ترمینال ۱ (سرور وب‌سوکت بازی):**
```bash
npm run ws
```

**ترمینال ۲ (اپلیکیشن Next.js):**
```bash
npm run dev
```

**ترمینال ۳ (ربات تلگرام تلگرام - اختیاری در لوکال):**
```bash
npm run bot
```

اکنون بازی در آدرس [http://localhost:3000](http://localhost:3000) در دسترس است.

## 🌐 راهنمای استقرار (Deployment)

### دیپلوی روی سرور لینوکس (VPS / Ubuntu):
1. نصب Node.js 20 و PM2:
   ```bash
   npm install -g pm2
   ```
2. بیلد پروژه Next.js:
   ```bash
   npm run build
   ```
3. مدیریت پروسه‌ها با PM2 (از طریق فایل پیکربندی آماده `ecosystem.config.js`):
   ```bash
   pm2 start ecosystem.config.js
   pm2 save
   ```
   یا راه‌اندازی دستی مجزا:
   ```bash
   pm2 start npm --name "crash-web" -- start -p 3000
   pm2 start ws-server.js --name "crash-ws"
   pm2 start server/bot.js --name "crash-bot"
   pm2 save
   ```
4. تنظیم Nginx به عنوان Reverse Proxy برای پشتیبانی از SSL/HTTPS و ارتقای وب‌سوکت (`Upgrade $http_upgrade`).
